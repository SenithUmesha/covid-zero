# 🦠 Covid Zero App

A mobile application that delivers real-time COVID-19 information, vaccination resources, and health guidance using reliable public APIs and clear data visualization.

This project demonstrates API integration, data visualization, location-based services, and user-focused health features in a single mobile application.

---

## 🚀 Features

* **Live COVID-19 Statistics**

  * Fetches up-to-date global and local COVID-19 data via public APIs
  * Visualizes trends using interactive charts

* **Vaccination Support**

  * Locate nearby vaccination centers
  * Online vaccine registration access

* **Self-Isolation Tracker**

  * Countdown timer to track isolation periods accurately

* **Latest COVID-19 News**

  * Aggregates verified news and updates related to the virus

* **Health & Safety Resources**

  * Provides essential guidance and public health information

---

## 🛠️ Tech Stack

* **Framework:** Flutter
* **Language:** Dart
* **APIs:** Public COVID-19 data APIs
* **Data Visualization:** Chart libraries
* **Platforms:** Android / iOS
